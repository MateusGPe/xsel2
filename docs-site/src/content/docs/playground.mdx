## Playground Tips

- **CLI Flags**: Edit the `$ xsel2 ...` bar and press **Enter** to test `-d <file>`, `-n <scraper>`, `-s <css>`, `-c` / `--compact`, or `-h` / `--help`.
- **Virtual Buffers**: Any filename passed to `-d` or `--html` automatically maps to the **DSL Pipeline** and **HTML Input** panes below.
- **Native-Only Flags**: Multi-threaded `--batch` / `-j` flags are disabled in the browser WASM sandbox; use the native `xsel2` binary for parallel batch scraping.
